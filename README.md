# Корни слов нео-квэнья, нео-синдарина и нео-праэльфийского по данным Eldamo

*English: [README.en.md](README.en.md).*

`neo-roots.json` — каждое слово перечней
[vocabulary-words-nq](https://eldamo.org/content/vocabulary-indexes/vocabulary-words-nq.html),
[vocabulary-words-ns](https://eldamo.org/content/vocabulary-indexes/vocabulary-words-ns.html) и
[vocabulary-words-np](https://eldamo.org/content/vocabulary-indexes/vocabulary-words-np.html) (Eldamo 0.8.13)
с корнем или набором корней:

| группа | слов | из них | с корнями | через `deprecated`/когнат/зачёркнутое |
|---|---|---|---|---|
| `nq` Neo-Quenya | 6060 | NQ. 2961, Q. 2058, ᴹQ. 1041 | 5530 | 70 |
| `ns` Neo-Sindarin | 3209 | NS. 1474, S. 1160, N. 575 | 2932 | 128 |
| `np` Neo-Primitive | 1571 | ✶ 969, ᴹ✶ 594, N✶ 8 | 1250 | 9 |

Кроме слов перечней, в `words` есть ещё четыре вида записей, с тем же разрешением корней и деревьями:

- **заменённые слова** (`deprecated: true`) — то, что Eldamo выводит на страницах deprecations-nq/ns/np
  (`deprecation-index.xq`: слова языков группы с `<deprecated>`, без имён, фраз, грамматики и фонетики; корни —
  в указателе корней): 3305 + 3021 + 31, корни найдены у 5496. `see_instead` — что Eldamo советует вместо;
- **формы других концепций** (`merged_into`) — статьи, вложенные в страницу слова и слитые с ним через
  `<combine>` (в Q. cala — ᴹQ. kala и ᴱQ. kala¹; Eldamo показывает их на странице слова под ним): 1663 + 940 + 54,
  корни у 2183;
- **прочие слова с ⚠️ вне перечней** (`outside_lists: true`) — слова языков группы, которые Eldamo помечает ⚠️ и
  не берёт ни в перечень, ни в список заменённых: ранние (G. caineglad, ᴱQ., ᴱN., ᴱ✶), отвергнутые, вычеркнутые, без
  значения (причина — в `warnings`). Без имён, фраз, грамматики, фонетики, корней и отсылок `<see>` (это лишь иные
  написания слов, которые и так есть): 630 + 831 + 429, корни у 1064. На графе они скрыты, пока не включена их
  галочка, — кроме 470, через которые идёт чьё-то дерево происхождения: те видны всегда, как прежде;
- **имена** (`name: true`) — имена языков группы (часть речи на `-name`: 1394 названия мест, 1247 мужских, 371
  женское, 851 прочее имя собственное, 211 собирательных вроде Q. Tareldar = tar-¹ + Elda). Eldamo не берёт их в
  перечни, но элементы и деривации у них те же, что у слов: 1548 + 2370 + 156, корни у 3357. На графе скрыты, пока
  не включена галочка «имена» (кроме 388, лежащих на чьём-то пути к корню); включённая галочка добавляет и имена
  из окрестности центрального узла — у Elda появляются Tareldar, Eldarion, Elendil и другие.

Счёт в `groups` (`count`, `with_roots`, `by_rule`) и указатель корней — по словам перечней; для четырёх других видов в
`groups` отдельные `deprecated`, `merged_forms`, `outside_lists` и `names`. Праформы, записанные капителью (ᴱ√ƷAWAKA), сюда не попадают — они
корни.

Собирается за несколько секунд, только стандартной библиотекой Python (подходит 3.8 на Windows 7):

```
python neo_roots.py data/eldamo-data.xml neo-roots.json          # все три группы
python neo_roots.py data/eldamo-data.xml ns-roots.json ns        # одна группа
python show.py neo-roots.json palantír huorn miltë               # просмотр записей в одну строку
python show.py --tree neo-roots.json palantír                     # дерево деривации
python show.py --root neo-roots.json LUP LAS¹                     # запись указателя корней
python show.py --en --tree neo-roots.json alda                    # подписи по-английски
```

`data/eldamo-data.xml` — модель данных Eldamo 0.8.13 из [pfstrack/eldamo](https://github.com/pfstrack/eldamo)
(`src/data/eldamo-data.xml`), © Paul Strack, CC BY 4.0. Подходит и любая новая версия того же файла.

## Перечни слов

Тот же отбор, что в `vocabulary-index.xq` при `id=nq`, `id=ns` и `id=np`: слова языков nq, q, mq / ns, s, n /
np, p, mp (eq, en, g и ep страница отсекает), без `<combine>`, `<deprecated>`, `<see>`, без имён, фраз, грамматики,
фонетики и самих корней, без `[unglossed]` и без `-` или `|` в `@mark`. Поле `spelling` — запись перечня:
у NQ нормализованная (`c:normalize-spelling`: q → qu, k → c, конечное -e → -ë), у NS и NP — как в базе.

Перечень NP — это праэльфийские *слова* (✶galadā, ✶lassē, ✶-i(n)ki), корни в него не входят: они сами — ответ.
В деревьях NQ и NS эти слова встречаются узлами-праформами, но лишь 716 из 1571 лежат на чьём-то пути к корню.
Запись N√GAWAK (корень, который Eldamo 0.8.13 размечает как существительное и потому выводит в перечне)
получает правило `self`: её корень — она сама.

## Файл

```json
{
 "source": {"eldamo_version": "0.8.13", "site": "https://eldamo.org"},
 "groups": {"nq": {"count": 6060, "with_roots": 5530, "by_rule": {…}, "uncertain": 70, …}, "ns": {…}},
 "words": [
  {
   "group": "nq", "word": "tyallas", "spelling": "tyallas", "lang": "nq", "lang_name": "Neo-Quenya",
   "speech": "n", "gloss": "(playing) card", "url": "https://eldamo.org/content/words/word-1340155721.html",
   "rule": "elements",
   "roots": [
    {"form": "TYAL", "lang": "mp", "url": "…", "gloss": "play", "part": 0,
     "via": [{"rel": "element", "lang": "q", "form": "tyal-", "url": "…"},
             {"rel": "combine", "lang": "mq", "form": "tyal-", "url": "…"}]},
    {"form": "LAS¹", "lang": "p", "url": "…", "part": 1, "via": […]}
   ]
  }
 ]
}
```

- `roots` — выбранные корни. Если у слова несколько частей (сложение), у корня есть `part`: корни с разными `part`
  складываются (√PAL + √TIR, S. huorn = ᴹ√KHUG + √ORO), корни с одним `part` — альтернативы
  (Q. alda: √GAL² / ᴹ√GALAD). Без `part` все корни — альтернативы одной части.
- `via` — цепочка от слова к корню: `element` (элемент), `deriv` (промежуточная форма), `combine` (то же слово
  другой концепции, слитое Eldamo), `see`, `deprecated`, `cognate`. Пустая цепочка — корень назван у самого слова.
- `same_as` — куда Eldamo сливает сам корень: цепочка его `<combine>` и нео-корень, под которым он записан
  (ᴹ√LUB² ≡ √LUB³ ≡ N√LUP). По последнему элементу удобно сводить корни разных периодов.
- `gaps` — части без корня на своих местах (Q. firya = √PHIR + -ya; суффиксы, слова без этимологии).
- `also` — корни из источников ниже рангом, которых нет среди выбранных; `rule` у каждого — откуда.
- `rule` — каким правилом выбраны корни; `uncertain` — если в цепочке есть `deprecated`, `cognate` или путь по
  зачёркнутой ссылке (`struck`; у такого корня и узла дерева тоже `struck: true`).
- `cognates` — раздел Cognates страницы Eldamo (`allReferenceCognates` + `allWordCognates`: слова других языков,
  связанные `<cognate>` через ссылки слова и само слово, транзитивно): S. Edhelharn ~ Q. Elessar. Это сопоставление,
  а не происхождение; корни через когнат по-прежнему берутся только правилом 8. Такие списки у 7486 записей. На графе
  — связь «когнат» без стрелки (5189 пар; 682 узла известны только как чей-то когнат — T., Ilk. и др. — и на карту
  истоков не попадают); когнаты центрального узла показываются сразу, в карточке — раздел «Когнаты». Счётчики
  «+N» по сторонам подписи их не считают, двойной щелчок раскрывает и их; в поиске пути когнат — нестрогая связь
  (вес 2) и смена ветви. Прежде граф показывал когнат, только если через него шёл путь к корню, поэтому у S.
  Edhelharn (корни — по элементам Edhel + sarn) когната Q. Elessar не было.
- `warnings` — за что Eldamo ставит ⚠️ перед словом на страницах перечней и замен: `deprecated` (своё
  `<deprecated>` или у слова, на которое ведёт `<see>`), `deleted` (`|`), `rejected` (`-`), `doubtful` (`‽`),
  `unglossed`, `early` (ᴱ✶, ᴱN., ᴱQ., G.). У слов трёх перечней их нет (перечни такие слова не берут); у заменённых —
  всегда `deprecated`; у форм других концепций — в основном `early`, а у 72 — и `deprecated`. `see_instead` бывает и у
  форм других концепций (ᴱQ. anda, отсылающая к заменённой ᴱQ. ande(a), → Q. anda). Замены нет только у двух
  заменённых слов: ᴹQ. áratenkele и S. dha (`<deprecated/>` без формы). На графе такие слова помечены ⚠ перед
  подписью (кроме форм, у которых только `early`), карточка называет причину и различает «заменено» и
  «не советуется, замены нет».
- `alt_lang` — язык, который Eldamo печатает в скобках после языка слова (`c:alt-lang`): ᴺQ. [ᴱQ.] ulumpë.
  У нео-слова с пометкой `^` это язык вложенной статьи, слитой с ним через `<combine>`; у слова без собственных
  ссылок — язык первой вложенной статьи со ссылками на другом языке. Так помечены 678 слов ᴺQ.[ᴱQ.], 420 ᴺS.[G.],
  156 ᴺS.[N.] и другие. У корней указателя — по правилу `root-index.xq` (корень без ссылок: язык первой
  вложенной статьи, ᴺ√ [√] LUP).
- `alt_source` — само это слово, основа нео-слова: `{"form", "id"}` (ᴱQ. aiko у ᴺQ.[ᴱQ.] aico). На графе основа
  появляется вместе с нео-словом, какого бы вида она ни была, и уходит вместе с ним: часто это слово, которое
  нео-слово заменяет (у 685 из 1479), и одна галочка «заменённые слова» его бы скрыла (ᴱQ. eldasilqe при ᴺQ.[ᴱQ.]
  eldafindë). Основа с другой формой (1057 слов) показывается и в результатах поиска пути: «основа: ᴱQ. eldasilquë»
  под ᴺQ.[ᴱQ.] eldafindë, если путь не проходит через неё саму.

### Дерево деривации (`tree`)

Те же выбранные корни и пропуски, но вложенными блоками: блок слова содержит свои части (`parts` — каждый
элемент отдельным блоком, по порядку) или альтернативы (`from` — разные деривации); в блоке элемента — то, из
чего он происходит, и так до корня: промежуточная форма → праформа → корень. У элемента могут быть свои элементы.

Если корни слова выбраны не по элементам (дериваций, промежуточной формой и т. д.) или их нет вовсе, в блоке слова
всё равно стоят его элементы (`parts`) рядом с деривациями (`from`): ᴹQ. mir < ᴹ√MĪ/IMI с суффиксом -r²,
Q. calima < √KAL с элементами cal- (< √KAL) и -ima, NQ. aialca = ai(a)- + -lka (оба без корня). На выбор корней
(`roots`, `gaps`, `also`) это не влияет; так дополнено 812 деревьев.

```
python show.py --tree neo-roots.json alda estolië lalië-malina
```
```
q alda (n) 'tree'  rule=deriv
   | deriv: p √GAL²  (напрямую; тот же корень и через праформу)
   | deriv: p ✶galadā
         записано PE17/135.4516: galadā > ʒalaðā > ʒalðā > alda
      | deriv: mp √GALAD
      | deriv: p √GAL²
nq estolië (n) 'camp'  rule=cognate ['cognate']
   cognate: s estolad
      [0] element: s estola-
         [0] element: p √ET  — без корня  ✗ не сошлись: ET
         [1] element: p √TOL
```

Узел: `rel` — как он связан с блоком выше (`element`, `deriv`, `combine`, `see`, `deprecated`, `cognate`),
`kind` — `root` (корень), `protoform` (праформа: слово праэльфийского языка), `form` (слово или промежуточная форма
другого языка); `form`, `lang`, `url`, `gloss`; у корня — `same_as`. Пропуск — `"gap": true`; корень части
неполного когната, чьих согласных нет в слове, остаётся на своём месте с `gap` и `not_matched`.

`shortcut: true` — корень, названный словом напрямую, когда рядом есть деривация, ведущая к тому же корню
через промежуточную форму. Eldamo часто записывает оба пути: Q. ‑(n)dur выведено из ✶‑ndūr < √(N)DUR (своя
`<deriv>`), а ссылка PE17/152 выводит *ndur* прямо из DUR. Оба пути сохраняются, прямой помечен как обходной;
таких слов 1007 (Q. alda: √GAL² напрямую и через ✶galadā). В плоском `roots` корень по-прежнему один.

`written` — как ссылки самого слова (не его словоформ) записывают связь с этим узлом: форма в написании источника
(`form`), место (`source`), форма ссылки (`ref`) и записанные промежуточные формы без своих страниц
(`intermediate`, от праформы к слову — как Eldamo печатает ✶v > i1 > i2 > i3 > слово). Пишется, только если
отличается от заглавной формы узла не одним регистром, √ или номером омонима.

Язык корня указан всегда (`p` — поздние √, `mp` — ᴹ√ «Этимологий», `np` — нео, `ep` — ᴱ√): Eldamo сам
связывает многие поздние слова с корнями ᴹ√ (Q. lár < ᴹ√DAR), так что, если нужны только поздние, фильтруйте по нему.

## Указатель корней (`roots`)

Корни перечня [roots-np](https://eldamo.org/content/root-indexes/roots-np.html) — тот же отбор, что в
`root-index.xq` при `id=np`: корни языков np, p, mp, ep без `<combine>` (1932). Нерекомендованные Eldamo в перечне
не отделяет, а помечает ⚠️; здесь это `recommended: false` и `warnings` с причинами, как у Eldamo:
`deprecated` (заменён, сам или корень, на который он отсылает; замена — в `see_instead`), `deleted` (`|`),
`rejected` (`-`), `doubtful` (`‽`), `unglossed`, `early` (ᴱ√). Рекомендованных — 1034.

```
python show.py --root neo-roots.json LUP
np LUP 'hump, lump, fat'  рекомендован
   под ним записаны: p LUB³, ep ULUN(T), ep ULUMP
   выводится из: np PUL
   nq (3): filiculumpe, ulumpë, ulumpembë
   ns (1): lûb
```

Запись: `form`, `lang`, `url`, `gloss` (и `ngloss`, если отличается), `mark`, статус, а также
`merged` (корни других концепций, слитые в этот через `<combine>`: в √LAS¹ — ᴹ√LAS¹ и ᴱ√LASA),
`filed_under` / `filed_here` (нео-корень, под которым корень записан, и корни, записанные под ним),
`see`, `derives_from` (корни, из которых выводится сам корень: ᴹ√GALAD < √GAL²) и
`derivatives` — слова трёх перечней, у которых этот корень среди выбранных, по группам, со ссылками на их
записи (`through` — если слово называет корень, слитый в этот: √LAS¹ получает и слова от ᴹ√LAS¹). Деревья и
значения слов не повторяются — они в записях слов по `url`. Корни из `also` производными не считаются.

1072 корней перечня имеют производные; 107 рекомендованных корней — ни одной (поле `derivatives` отсутствует):
это готовый список для словотворчества.

Шесть корней, на которые опираются слова, в перечень Eldamo не попадают; они добавлены с `in_list: false` и
причиной в `not_listed_because`, чтобы указатель покрывал все слова: `merged_into_word` — Eldamo слил корень не в
корень, а в праэльфийское слово (ᴹ√LŌ → ✶lō¹, ᴱ√SA → ✶sa, ᴱ√LĒ → ✶dē, ᴹ√AKLA(R) → ✶aklar(a));
`combined_with_itself` — `<combine>` указывает на сам корень (ᴹ√LA), и перечень Eldamo его теряет;
`not_marked_root` — корень размечен как существительное (N√GAWAK).

## Граф (`neo-roots-graph.html`)

Интерактивная страница на d3: узлы — корни, праформы и слова, стрелки — от источника к производному, цвет и
рисунок линии по типу связи (деривация, элемент, слияние форм, заглушка, замена, корень через когнат, а для корней —
слияние, запись под другим корнем, вывод из корня; и когнаты — без стрелки, это сопоставление, а не происхождение).
Весь граф — 29 249 узлов и 48 684 связи, почти все в одной
компоненте, — разом не рисуется: это и медленно, и нечитаемо. Страница показывает окрестность: выбранное слово
с его деревом до корней и ближайшими производными или корень с производными на два шага; двойной щелчок по
узлу разворачивает его соседей, «+N» справа от подписи — сколько производных узла ещё скрыто, слева — сколько источников. Обходные связи
(`shortcut`) по умолчанию скрыты, чтобы путь шёл через промежуточную форму; переключатель в легенде их показывает,
а в карточке слова они видны всегда, с пометкой «напрямую». Связи каждого типа можно
отключить в легенде. Адрес `#n-<страница Eldamo>` открывает узел сразу; если такой страницы на графе нет (фраза, грамматика), внизу об этом сказано.

Повторный двойной щелчок по развёрнутому узлу сворачивает его. Неоднозначности здесь нет: каждый показанный узел
помнит, что его держит, — центр с его деревом или узлы, при разворачивании которых он появился. Сворачивание
убирает только то, что держал один этот узел, вместе с тем, что успели развернуть убранные узлы; узел, который
держит ещё что-то (центр, его дерево, другой развёрнутый узел), остаётся.

Язык в скобках (`alt_lang`) выводится, как у Eldamo: ᴺQ.[ᴱQ.] ulumpë; у корней — только если он отличается от
языка самого корня (ᴺ√[√]LUP, но не ᴹ√[ᴹ√]DIM).

Вид «Карта истоков» (адрес `#all-roots`) — всё, с чего начинаются цепочки происхождения, тремя независимыми
галочками: корни перечня roots-np (1932), праформы без корня (324) и прочие слова без корня (890). «Без корня» —
узел не достижим ни от одного корня по связям происхождения (несошедшаяся часть неполного когната не в счёт); это
слова перечней, у которых в JSON нет корней, и 80 элементов вне перечней (суффиксы вроде ᴹQ. -r²). Круги сгруппированы по виду и первой букве, площадь
круга — число производных слов перечней (у корня — из указателя, у прочих — сколько слов перечней из него
выводится: Q. ‑itë — 76, ✶‑mā — 103). Закрашен рекомендованный корень, пунктиром — корень с ⚠; праформы и слова —
цветом своего перечня. Фильтры корней: концепция (поздние √, ᴹ√, ᴱ√, ᴺ√) и «только рекомендованные»; «только без
производных» действует на все три вида (рекомендованные корни без производных — те 107, из которых ещё ничего не
образовано). Подписи появляются при увеличении; щелчок открывает карточку, двойной щелчок — граф узла. Все
истоки сразу на силовом графе были бы россыпью из трёх тысяч несвязанных точек, поэтому они собраны в карту.
Карта рисуется на canvas, и только то, что на экране: в svg тысячи кругов с подписями заново раскладывали текст
на каждом шаге увеличения, и кадр занимал десятки миллисекунд.

В легенде графа:

- **заменённые слова** — по умолчанию скрыты; включённые, показываются бледными, а связь «вместо него» ведёт от
  такого слова к тому, что Eldamo советует вместо (в карточке — разделы «Вместо него Eldamo советует» и «Заменяет»).
  Эта связь — не происхождение и в деревья не входит;
- **прочие слова с ⚠️ вне перечней** — по умолчанию скрыты (кроме лежащих на чьём-то пути к корню); включённые,
  показываются бледными с пунктирным контуром и знаком ⚠;
- **формы других концепций** — слово и вложенные в него формы (а у корней — слитые с ним и записанные под ним корни):
  способ раскладки описан ниже;
- **языки** — по ветвям (квенийская, синдаринская, праэльфийский, другие эльфийские) с числом узлов. Скрытый язык не
  рвёт цепочек: путь через скрытые узлы показывается одной пунктирной связью «через скрытое». Фильтр действует и на
  карту истоков (корни — это языки √, ᴹ√, ᴱ√, ᴺ√). Центральный узел виден всегда.

Пометы языков на графе цветные: тон — ветвь (квенийская — бирюзовый, синдаринская — зелёный, праэльфийский —
фиолетовый, другие эльфийские — оранжевый, корни — золотой), насыщенность и сила — новизна языка: ранний бледнее,
нео — глубже всего на светлой странице и ярче всего на тёмной. Концы стрелок стоят на краю узла с той стороны,
откуда приходит связь (у выделенного узла — на краю кольца).

Раскладка вычисляется, а не набирается пружинами. Колонки слева направо — стадии: корень, праформа, древний язык
(древнеквенья, древнетелерин, старосиндарин, староолдорин), язык (квенья, синдарин, телерин, нолдорин, нео…); узел
стоит не левее своей стадии и правее всех своих источников, поэтому праформа, выведенная из того же корня, что и
слово, всегда левее слова. Порядок в столбце выбирается в легенде: **по источникам** (по умолчанию) — производные
одного источника вместе, и среди них квенийская ветвь сверху, ниже синдаринская, другие эльфийские, праэльфийский;
**по ветвям** — сначала все квенийские слова столбца, потом все синдаринские и т. д., внутри ветви по источникам;
**по алфавиту**. Каждый узел ставится как можно ближе к своим источникам, насколько позволяют соседи
(три прохода: по источникам, по производным, снова по источникам). Порядок столбцов задают только связи
происхождения: «вместо него» (заменённое слово и его замена) его не определяет, а циклы — их в данных 241, почти все
через «вместо него», и два настоящих (S. lhaw ~ N. lhewig, Q. tyelpë ~ telpë) — разрезаются обходом в глубину.
Раньше цикл отодвигал свои узлы на 40 столбцов: у Q. telpë граф выходил шириной 9000 px, и производные
разрывались на два далёких столбца. Узлы с подписями расталкиваются
прямоугольниками, чтобы не перекрываться.

Формы других концепций раскладываются одним из трёх способов (выбор в легенде): **полосами** (по умолчанию) — слово
и его формы других концепций в одной колонке, а концепции — горизонтальными полосами: нео-эльдарин, поздняя, средняя
(«Этимологии»), ранняя. Нео стоит своей полосой: его слова и корни ввели составители, а не Толкин, и от поздней
концепции он отличается так же, как концепции Толкина друг от друга; столбцы у полос общие, так что неологизм
стоит над своим источником (ᴺQ.[ᴱQ.] eldafindë — в столбце после Q. Elda). Высота полосы — по её самой полной колонке, узел не выходит из своей полосы ни при раскладке,
ни при перетаскивании, так что полосы не пересекаются; **под своим словом**, как на странице Eldamo; **отдельно** — обычными стрелками.

Щелчки: одиночный — карточка; двойной — развернуть соседей, повторный двойной — свернуть развёрнутое этим узлом;
тройной (или кнопка «Свернуть производные») — убрать всё, что выводится из узла, кроме центра и его дерева
происхождения: так сворачиваются и производные центрального слова, показанные с самого начала. Перетаскивание
двигает узел вместе с тем, что держится только на нём (производные без других видимых родителей), с Shift — один
узел; перемещённое остаётся на месте (обводка толще), «Перестроить» снимает закрепления. Пружин между узлами нет,
поэтому перемещённое не стягивается обратно, а остальные узлы не сдвигаются.

У подписи узла два счётчика нераскрытых связей: справа «+N» — производные (последующие формы и слова, где узел —
элемент), слева «+N» — источники (прежние формы, элементы, слитые с ним формы, когнаты, корень, под которым он
записан); так же они и раскладываются: источники левее, производные правее. Двойной щелчок с Shift раскрывает
только производные, с Ctrl (или Alt, ⌥) — только источники; если на этой стороне раскрывать нечего, он сворачивает
развёрнутое узлом. То же — кнопками «← Источники» и «Производные →» в карточке. Связь когната особой обработки не
требует: на графе когнат стоит только на пути к корню и потому всегда источник.

Связи огибают узлы с подписями (и подписи своих же концов). Связь рисуется обычной S-образной кривой, пока та не
задевает ни одного узла на своём пути. Если задевает, сначала ищется проход: через участок (столбец узлов) — одной
точкой на ближайшей к курсу свободной высоте, а не выйдет — горизонтально; у своих концов связь плавно входит
в просвет вокруг их высоты. Когда граф успокоится, по найденному проходу проводится самая плавная кривая: натянутая
нить через коридор между узлами (огибает только те углы, которые обойти необходимо), а через её изломы — кубическая
кривая с наклоном той стороны, где стоит узел, так что поворот начинается лишь за ним. Если она что-то задевает,
остаётся проход. Кроме того, промежуток между столбцами расширяется по самому крутому перепаду высот связи, которая
его пересекает (у связи через несколько столбцов перепад делится между ними): на √ET спуск от Q. et к его
производным раньше втискивался в узкий промежуток и давал резкий поворот перед самым узлом. Пока узлы движутся (раскладка,
перетаскивание), связи — простые S-кривые; обход и сглаживание считаются, когда граф остановится: на каждом кадре
они занимали почти всё время раскладки (у 168 узлов — 4,9 из 6 с работы скриптов, теперь 0,6 с). В коридор
длинной связи берутся только узлы около её хода, а не все узлы её столбцов, а узлы расталкиваются проходом по x,
а не сравнением всех пар: у вида на 1719 узлов заминка после остановки — 0,27 с вместо 3 с.

Граф, как и карта истоков, рисуется на canvas; svg над ним пустой и принимает указатель (масштаб, сдвиг, выбор узла
и связи по их геометрии, перетаскивание). В svg каждый шаг масштаба и каждый кадр раскладки заново раскладывал
текст всех подписей: на виде из 871 узла раскладка шла около 30 кадров в секунду, масштаб — около 11, после
остановки поток вставал на 0,64 с; на canvas — 60 кадров, вдвое меньше работы на шаг масштаба и 61 мс. Подписи,
мельче 3 пикселей на экране, не рисуются (кроме фокуса и выбранного узла), пунктир при сильном отдалении рисуется
сплошной бледной линией: штрихи короче пикселя не видны, а обходились в тысячи кусочков на линию. Подсказки
(что было в svg `<title>`) показывает всплывающая плашка. Перетаскивание начинается с первого движения: щелчок по
узлу больше не закрепляет его.

Щелчок по связи выделяет её и оба её конца (остальное бледнеет), карточка показывает отношение, источник,
производное и как связь записана в источниках; щелчок по пустому месту или Esc снимает выделение.

**Словарь** (переключатель в легенде): «нео-эльдарин» — как страницы Eldamo с `?neo`: неологизмы ᴺQ., ᴺS., ᴺ✶,
ᴺ√, знак ⚠, заменённые слова и замены «вместо него»; «только Толкин» — как Eldamo без `?neo` (там скрыто всё
с классом `neo`, `c:is-neo`): неологизмы скрыты, а слова, которые Eldamo не советует для нео-эльдарина, и прочие
слова с ⚠️ становятся обычными словами своих языков — без ⚠, без бледности и без связей «вместо него»; их галочки
тогда не действуют. Так же и слова, влитые (`<combine>`) в другое ради нео-эльдарина: с `?neo` Eldamo перенаправляет
их страницу на то слово (ᴱQ. aiko → ᴺQ.[ᴱQ.] aico), без `?neo` каждое — самостоятельное слово своего языка.
В режиме «только Толкин» связи «влитая форма» не показываются и не участвуют в поиске пути, такие слова (855 влиты
в неологизмы, остальные — в слова Толкина из перечней) рисуются обычными, а не полыми, без пометы «форма другой
концепции», карточка не называет ни их слияния, ни неологизмов, а на карте истоков они стоят сами по себе. Сам маркер
ᴺQ.[ᴱQ.] относится к неологизму и в этом режиме скрыт вместе с ним. Выбор запоминается в браузере.

**Путь между словами** (панель под поиском; концы — в полях или кнопками «путь отсюда» / «путь сюда» в карточке;
адрес `#path-<A>-<B>-<вид>-<переходы>`). Три вида:

- **родство** — ближайший общий источник: поиск вверх по связям происхождения от обоих концов, источник с
  наименьшей суммой двух цепочек (Q. telpë и S. celeb — ✶kyelepē; Q. Elda и S. Edhel — ✶edelā);
- **происхождение** — выводится ли одно из другого, по направлению связей (√GAL² → ✶galadā → alda →
  aldarembina), в любую сторону;
- **любая связь** — кратчайшая цепочка по всем связям в обе стороны.

Шаг, **пересекающий концепции** (слитая форма, корень другой эпохи, замена, деривация из другого периода; чистый
неологизм ᴺQ., ᴺS., ᴺ✶, ᴺ√ — своя концепция, нео-эльдарин, а слово, взятое в нео у Толкина, ᴺQ.[ᴱQ.] aico, — концепция
языка в скобках: ᴱQ. aiko → ᴺQ.[ᴱQ.] aico не пересечение, а ᴺQ. от позднего √ — пересечение), или **ветви** (когнат, заимствование, «см.» между квенийской и синдаринской ветвью;
путь через праформу ветвь не меняет: праэльфийский общий у обеих), отмечается и на графе (пунктир), и в списке шагов
(«↕ смена концепции», «↔ смена ветви»). Переходы: как можно меньше (сравнение по порядку: число переходов между
концепциями, потом между ветвями, потом длина), запрещены, только между ветвями, только между концепциями или не
учитываются. Веса связей: деривация и элемент 1, слитая форма 0,5, «см.», когнат и замена 2, «вместо него» 3,
зачёркнутая ссылка +2; «согласные не сошлись» не проходимы; нестрогие связи можно исключить галочкой. Учитываются
языки и виды слов, выбранные в легенде. Кроме лучшего пути, показываются ещё до двух (найденных с надбавкой к весу
уже пройденных связей), а если запрет переходов сделал путь заметно длиннее — и кратчайший путь с переходами.
Путь добавляется на граф, остальное бледнеет; поиск по всему графу (28 тысяч узлов) — алгоритм Дейкстры, миллисекунды.

«Экспорт»: граф на экране — SVG (собирается из тех же данных и по тем же правилам вида, что и холст; файл
самодостаточен), PNG (тот же рисовальщик холста, вдвое крупнее; шрифт берётся системный, если веб-шрифт
недоступен) и JSON (узлы с id, формой, языком, глоссой и адресом
Eldamo, связи с отношением, пометами и записями); на карте истоков — PNG всей карты 4000×4000. В артефакте файл
передаётся через сохранение хоста (с подтверждением), в отдельном файле страницы — обычной загрузкой.

Пометка «согласные не сошлись» (`nm`) ставится на связь графа, только если она не сошлась во всех деревьях, где
встречается: связь √MEL → ✶melnā не сошлась в дереве S. edhelvein (через неполный когнат Q. vanimelda), но в
дереве Q. melda это настоящая деривация.

```
python make_graph.py neo-roots.json graph_template.html neo-roots-graph.html --standalone
```

`graph_template.html` — сама страница с метками `/*GRAPH*/` и `/*MESSAGES*/`, куда `make_graph.py` вписывает граф
(4,4 МБ) и каталог интерфейса; без `--standalone` получается тело страницы для размещения на хостинге, который сам
добавляет `<head>`. Для GitHub Pages страница собирается с `--standalone` в `index.html` в корне репозитория (или
в `docs/`, если Pages настроены на эту папку): данные вписаны в саму страницу, так что больше ничего не нужно;
вне Claude экспорт сохраняет файлы обычной загрузкой.

Тема — как в системе (или в окне, где открыта страница); кнопка ◐/☀/☾ рядом с кнопкой языка переключает «авто →
светлая → тёмная», выбор хранится в браузере.

Интерфейс двуязычный, русский и английский, как у Quettamin: каталог `graph_messages.json` (`ключ → {ru, en}`,
подстановки `{имя}`), статичная разметка помечена `data-i18n` и `data-i18n-attr`, остальное страница строит через
`t(ключ)`. Язык — последний выбранный кнопкой (хранится в браузере), иначе язык браузера; переключение
перерисовывает страницу на месте, открытый граф сохраняется. Данные Eldamo (формы, значения) не переводятся.
Новый язык — ещё одно поле в каждой записи каталога и в переключателе.
d3 7.8.5 грузится с cdnjs, шрифты — с Google Fonts, так что открывать файл нужно при подключении к сети.

## Правила, по старшинству

1. **elements** — два и больше элемента с корнями: корни по частям. Элементы берутся у статьи, а если их нет —
   из одной её ссылки: среди ссылок с той же формой (иначе среди всех) — с наибольшим числом элементов (G. Tol
   Erethrin: tol + erethrin из LT1A, а не одно tol из GL). Ссылка, среди элементов которой названо само слово, разбирает
   его форму (ᴹ✶apparkā, усилительная форма ᴹ✶parkā = ᴹ√A + parkā): её прочие элементы — аффиксы этой формы, а не
   части слова, и корнями слова не считаются. Корень, который ссылка называет вместо элемента без
   этимологии, занимает его место, если начинается с той же согласной (S. huorn: hû¹ → KHUG); аффиксы так не заполняются.
2. **deriv** — корни, названные деривациями слова: `<deriv>` статьи и `<deriv source>` внутри её ссылок (по `@source`,
   как `c:get-ref`). Корни, к которым ведёт промежуточная форма (✶galadā < ᴹ√GALAD), добавляются как альтернативы.
3. **element** — один элемент с корнем, остальные — пропуски.
4. **intermediate** — только через промежуточные формы (Q. lassë < ✶lassē < √LAS¹). Промежуточные формы разного
   строения — альтернативы той части, у которой есть корни: Q. Elda < ✶elenā (= ✶elen < √EL + ✶-ā), а также
   < ✶eledā < √EL, < ✶edelā < √DEL², < ✶edelō < √DEL¹ — корни √EL, √DEL², √DEL¹ одной части. (До 2026-11-01
   форма с бóльшим числом частей вытесняла остальные, и у Elda оставался один √EL.)
5. **combine** — через слова, слитые с этим (NQ. hlöa ← Q. hlöa < ✶(s)loga < √LOG).
6. **see** — через ссылку-заглушку.
7. **deprecated** — через слово, которое это заменило. Принимается, только если оно начинается с той же
   согласной (b~v~w, k~c~g~h, p~f, t~d~th, n~ñ, rh~r, lh~l) или обе формы с гласной, и согласные всех его
   корней есть в слове. Так проходят старые формы того же слова (ᴱQ. milt → NQ. miltë; N. lhoch → NS. loch,
   N. rhand → NS. rand, N. tofn → NS. tovn), а не проходят другие слова (NQ. sin → latúcen, Q. engë → né,
   ᴱQ. wara- → psar-, G. cwiliog → S. calen). Корень, заменённый словом, считается его корнем, только если
   слово начинается с той же согласной (ᴱ√SINI → ✶sinki — да, ᴱ√GWAṘA → psar- — нет).
8. **cognate** — через когнаты (транзитивно, как раздел Cognates); только эльфийские языки, только корни, чьи
   согласные (не меньше двух) есть в слове; часть составного когната, не найденная в слове, — пропуск с `not_matched`.
9. **struck** — через деривации ссылок, которые Толкин зачеркнул (`-` в `@mark` ссылки). Страница слова в Eldamo
   перечисляет их среди Derivations (так `word-page.xq` берёт все ссылки, а не только действующие): ᴹQ. Elda
   < ᴹ√LED («ушедший» эльф, Ety/ELED) и < ᴹ✶edēlā < ᴹ√EDE(L) (EtyAC). Берутся только формы, до которых не доводят
   действующие ссылки; если корни дало другое правило, такие пути попадают в `also` (`rule: struck`) и в дерево
   с пометой `struck`, а на графе — штрихпунктиром с пометой «зачёркнуто». Слово, чьи корни идут через такой путь,
   получает `uncertain: struck`.

Проверка согласных учитывает ветвь слова: для синдарина ch, dh, lh, rh, mh — один звук, m сходится с
губными (ленция m > v), а велярный и y корня могут выпадать (медиальное g, y > i); для квенья ngw = ŋg, gw > w.

Осторожности ради:

- когнаты не используются ниже самого слова (у элементов и промежуточных форм), а у когната не учитываются
  корни, найденные через `deprecated` или другой когнат;
- корень когната попадает в `also`, только если и слово, и когнат несоставные: N. anrand (= ann + rand) не даёт
  ᴹQ. randa корень ᴹ√ANAD, S. dagnir не даёт Q. nehtar корень √N(D)ER;
- отвергнутое Толкином (`-` в `@mark`) не учитывается, если само слово не отвергнуто, — кроме деривации зачёркнутых
  ссылок (правило 9), и то лишь низшим рангом;
- праформы, записанные капителью, считаются корнями: в 0.8.13 N√GAWAK, ᴱ√ƷAWAKA и ᴱ√OWO размечены как существительные;
- циклы (Q. nelquë ↔ quainel) обрываются; результат детерминирован.

## Сверка с Quettamin

До версии 3.10 разрешение корней `quettamin/shared/lexicon.py` совпадало с этим для 5588 слов NQ из 6060 и 2914 слов
NS из 3209 (слов, где корень нашёл только Quettamin, не было). В 3.10 Quettamin перешёл на эти правила (по его
журналу — 9696 совпадений из 9709), в 3.11 взял указатель корней и дерево происхождения. Обходные пути (`shortcut`)
появились здесь позже: Quettamin пока сливает альтернативы одной части по корню (`shared/lexicon.py`, `alts` и
слияние в `_root_groups`), и путь через праформу при совпадении корня у него теряется.

Сверка с Quettamin 3.20 (2026-11-01, его `_resolve_roots` на тех же страницах): корни совпали у 25 669 записей из
25 818. Расхождения: у Quettamin нет корней, которые здесь дают промежуточные формы другого строения (Q. Elda и его
производные: √DEL², √DEL¹ через ✶edelā, ✶edelō — его `_merge_groups` отбрасывает их, как прежде и здесь), и
деривации зачёркнутых ссылок (правило 9: ᴹQ. alwa < ᴹ√GAL², ᴹQ. alla¹). Два места, где точнее был Quettamin,
перенесены сюда: элементы из ссылки с самым полным разбором (G. Tol Erethrin, ᴱQ. Meril-i-Turinqi — у ранних имён
так нашлось ещё около 50 корней) и отказ от ссылки, разбирающей форму самого слова (ᴹ✶parkā больше не выводится
из ᴹ√A; у самого Quettamin ᴹ✶parkā < ᴹ√A пока остаётся).

Без корня остались в основном суффиксы, местоимения, частицы и слова, у которых Eldamo не даёт этимологии
ни у себя, ни у слитых форм (S. rhîw «зима», Q. fúmë «дыхание»; у праформ ✶tulku, ✶dankĭnā, ✶stama- есть
только ссылка на источник — корень по форме очевиден, но Eldamo его не связывает, и здесь он не угадывается).
